# 1.1.0 - 2026-10-20

## Añadido

- Consolas de logs por servicio, con selector, rango temporal, actualización automática y diseño responsive.
- Endpoint de consulta de Loki en modo de solo lectura, limitado a servicios permitidos, períodos de hasta una hora y 100 líneas.

## Cambiado

- Los servicios y contenedores MySQL ahora se llaman `main`, `fallback` y `slave`.
- Prometheus, ProxySQL, la interfaz y las guías muestran los nuevos nombres.
- Se conservaron los alias DNS internos `mysql-1`, `mysql-2` y `mysql-3` para mantener la metadata existente de InnoDB Cluster y la configuración de ProxySQL. Los nombres no fijan el rol PRIMARY/SECONDARY.

## Seguridad

- La consola muestra logs como texto y no permite ejecutar comandos ni acceder al socket Docker.
- La API de logs usa una lista de servicios permitidos y limita el período y la cantidad de resultados.

## Verificado

- El clúster existente se recuperó con sus tres miembros `ONLINE`; los contenedores `main`, `fallback` y `slave` quedaron `healthy`.
- Prometheus muestra los tres objetivos MySQL renombrados.
- La API web informa el nodo `main`, la consulta de logs responde correctamente y la aplicación devuelve HTTP 200.
