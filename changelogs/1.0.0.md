# 1.0.0

Primera versión del proyecto Docker CUTSA.

## Incluye

- Aplicación web con Apache y PHP 8.3.
- Clúster MySQL 8.0 de tres nodos con InnoDB Cluster y Group Replication.
- MySQL Shell para inicializar el clúster y ProxySQL para enrutar conexiones.
- Observabilidad con Prometheus, Grafana, Loki, Alloy, Alertmanager, cAdvisor y MySQL exporter.
- Perfiles opcionales para inspección IDS con Suricata y copias de observabilidad por WebDAV.
- Persistencia de datos mediante volúmenes de Docker Compose.
